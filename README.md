## 🔤 3. Manipulation de Chaînes (Problèmes 23–44)

Techniques avancées de traitement de texte en C++ :

### ✔ Modification de la Casse
- Mettre la première lettre en majuscule/minuscule  
- Transformer tout en majuscules / minuscules  
- Inverser la casse caractère par caractère  

### ✔ Comptage
- Nombre de majuscules / minuscules  
- Comptage d’un caractère précis (case sensitive / insensitive)  
- Nombre de voyelles  
- Nombre de mots  

### ✔ Découpage & Formatage
- Fonction `Split`  
- Fonction `Trim` (début, fin, ou deux côtés)  
- Fonction `Join`  

### ✔ Manipulation de Mots
- Inverser l’ordre des mots  
- Remplacement de mots (custom + replace)  
- Suppression de toute la ponctuation

## 📂 4. Gestion de Données & Fichiers (Problèmes 45–51)

Mini-système CRUD de gestion de clients bancaires.

### ✔ Conversion
- `struct` → ligne texte (CSV)
- ligne texte → `struct`

### ✔ Opérations CRUD
- **Create** : ajouter un client  
- **Read** : lire tous les clients + chercher par numéro  
- **Update** : modifier les infos d’un client  
- **Delete** : supprimer un client
